# IP 一键切换工具

这是一个给 Windows 用的小工具，打开后可以：

- 选择网卡
- 预先保存多个 IP 配置
- 点一下应用预设
- 一键切回自动获取 IP 和 DNS
- 读取当前网卡配置，方便保存成预设

## 开源说明

本项目源码公开，采用 `MIT` 许可证发布。

源码文件：

- `ip_switcher.ps1`
- `start_ip_switcher.cmd`
- `启动-IP切换工具.cmd`

## 启动方式

优先双击：

`IP切换工具.exe`

如果你想用脚本版，也可以双击：

`启动-IP切换工具.cmd`

第一次修改 IP 时会提示管理员权限，点确认即可。

## 默认预设

工具目录里已经带了两个示例预设：

- 公司网络
- 家里网络

你可以直接改成自己的 IP 段再保存。

## 预设保存

预设会保存在同目录的 `ip_presets.json` 里。
